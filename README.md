## 공통 원칙 (제0지침)

모든 프로젝트는 다음을 따릅니다.

1. 모르면 모른다고 한다. 섣부른 추론을 하지 않는다.
2. 사실 주장에는 공개 출처를 붙인다. 근거가 부족하면 "근거 부족"으로 표시한다.
3. 사실 · 가정 · 의견 · 추천을 구분해서 작성한다.
4. 위험도 등급(Tier 0~3)에 맞는 절차만 적용한다 — 과설계 금지.
