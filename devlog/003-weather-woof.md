# 003 · Weather Woof (날씨멍) — 시바견이 날씨를 브리핑하는 앱

> 날씨에 맞춰 **옷을 갈아입은 시바견 캐릭터**가 오늘 날씨와 옷차림을 브리핑해 주는 iOS 앱.
> 숫자와 그래프 대신, 귀여운 캐릭터 한 컷으로 "오늘 뭐 입지?"에 답한다.

- **분야:** iOS · Flutter · 날씨
- **위험도:** Tier 1 (가벼운 사용자 입력, 광고)
- **상태:** **App Store 출시 실패 — 개인 사용 중**

## 왜 만들었나

날씨 앱은 대부분 "정보"를 준다 — 기온, 강수확률, 미세먼지 숫자.
하지만 사람들이 실제로 궁금한 건 "**그래서 오늘 뭐 입고 나가지?**"다.
숫자를 옷차림이라는 **행동 언어**로 번역하고,
그걸 귀여운 캐릭터가 대신 말해주면 매일 열어보고 싶은 앱이 된다는 가설.

## 무엇을 만들었나

- **날씨 옷차림 캐릭터** — 2D 시바견 마스코트가 오늘 날씨에 맞는 옷을 입고 등장한다.
- **데일리 브리핑** — 매일 알림으로 오늘 날씨 + 옷차림 제안을 보낸다.
- **홈 위젯** — 홈 화면 위젯으로 앱을 열지 않고도 오늘의 브리핑을 확인한다.
- **다국어** — 영어·한국어·일본어.

기술적으로는:

- **Flutter** UI + **Swift 코어(WeatherFitKit)** 조합.
- **Apple WeatherKit** 기반 — 별도 백엔드 서버 없이 동작(**서버리스**). 로그인·인앱 구매 없음.
- **위젯 / 알림** — 잠금화면·홈화면에서 브리핑을 노출.
- **광고** — 비개인화 배너 1개로 최소한의 수익화.

## 만드는 과정

- **리서치·기획** — "날씨 정보"가 아니라 "옷차림 행동"으로 번역하는 규칙을 먼저 정의.
- **디자인** — 마스코트 캐릭터 아트와 날씨별 옷차림 세트 제작.
- **빌드** — WeatherKit 연동 → 옷차림 매핑 로직 → 위젯 → 알림 → 3개 언어.
- **릴리즈** — 릴리즈 플랜 / 롤백 플랜 / 개인정보 처리방침 정리 후 심사 제출.

## 배운 점

- **정보를 "행동"으로 번역하면 UX가 단순해진다.** 기온 23°C를 보여주는 대신
  "가벼운 긴팔"을 입은 캐릭터를 보여주면 판단이 끝난다.
- **서버리스는 운영 부담을 극적으로 줄인다.** WeatherKit로 데이터 소스를 위임하니
  백엔드·DB·인증이 통째로 사라졌다. 그만큼 보안 표면도 작아졌다.
- **위젯과 알림은 "앱을 안 열게 만드는" 기능이다.** 역설적으로 그게 매일 쓰게 만든다.
- **문서와 코드의 동기화.** 진행 중 광고 ID가 테스트→운영으로 바뀌면
  보안 문서의 "테스트 ID만 존재" 서술이 낡는다 — 문서-코드 싱크를 릴리즈 게이트에 포함해야 했다.

## 그래서 어떻게 됐나

**심사를 통과하지 못했고, 출시하지 않았다.** 지금은 만든 사람이 자기 기기에 넣고 쓴다.

빌드가 덜 됐던 것은 아니다. 3개 언어, 위젯, 잠금화면 액세서리, 강수 알림, 스크린샷 17컷,
릴리즈·롤백 문서까지 제출 직전 상태는 다 갖춰져 있었다. 스토어에 올리는 일은
만드는 일과 별개의 일이고, 후자를 끝냈다고 전자가 끝나지 않는다.

접었다기보다 **범위가 줄었다.** 매일 아침 시바견이 오늘 옷차림을 알려 주는 것,
그 원래 목적은 기기 하나에서 여전히 작동한다. 출시되지 않은 앱도 쓰이면 도구다.
